Atelier de tableaux de variations

Construisez votre tableau : les signes, les valeurs et les flèches sont vos réponses. Le logiciel les met en forme sans les calculer ni les vérifier.

Saisissez directement vos expressions : 2x^2-3x+1, 1/x, sqrt(x), e^x, ln(x), pi, +inf, -inf. Elles sont converties automatiquement. Les boutons restent disponibles.

La valeur de f′(a) est facultative aux points ordinaires. Un champ vide n’affiche rien. Pour un zéro de la dérivée, le logiciel affiche 0 ; pour un point non dérivable, il affiche ND. Les signes sur les intervalles se renseignent séparément.

Signes et variations sur les intervalles

Saisissez les abscisses dans l’ordre croissant : cet ordre n’est pas vérifié. Pour −∞ ou +∞, choisissez « Borne ouverte / infini » et renseignez la limite du côté du domaine. La hauteur des flèches est schématique, sans échelle. Les points définis présentant un saut ne sont pas pris en charge.

Chargement des notations mathématiques…

Double barre : point exclu ou borne ouverte. ND : fonction définie mais non dérivable. Les expressions de chaque côté d’une double barre sont des limites.
